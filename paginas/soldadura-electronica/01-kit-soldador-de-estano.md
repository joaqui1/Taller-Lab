# Kit soldador de estaño: elegí el equipo según la reparación

Un **kit soldador de estaño** puede servir para cables, conectores y placas simples, pero los paquetes de Mercado Libre reúnen herramientas muy distintas bajo el mismo nombre. La pregunta principal es si el soldador permite **controlar la temperatura** y conseguir puntas de repuesto. La cantidad de accesorios impresos en la foto no compensa una punta inestable o un mango incómodo.

Esta guía trata soldadura electrónica con cautín. Para unir hierro con electrodo o alambre Flux, consultá las [guías de soldadoras](/soldadoras/): el proceso, los consumibles y la protección requerida son diferentes.

## Equipo mínimo útil

| Componente | Qué revisar al comparar kits |
| :--- | :--- |
| Cautín o lápiz | Tensión de alimentación, temperatura regulable y disponibilidad de puntas compatibles. |
| Soporte | Que mantenga la punta caliente separada de la mesa y del cable. |
| Limpieza | Esponja de celulosa o lana de latón para retirar residuos sin dañar la punta. |
| Consumible | Aleación, diámetro y cantidad de alambre de soldadura; no confundir con pasta o flux. |
| Herramienta de desoldado | Bomba o malla, según el tipo de reparación. |

Una pinza, un multímetro o una lupa son útiles solo si vas a usarlos. Si trabajás habitualmente sobre placas, una [estación de soldadura electrónica](/soldadura-electronica/estacion-de-soldadura/) con soporte estable y control de temperatura puede resultar más cómoda que un lápiz económico. Para componentes pequeños, un [soporte con lupa y pinzas](/soldadura-electronica/soporte-para-soldar-con-lupa/) libera las manos.
