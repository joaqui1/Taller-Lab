# Hidrolavadora Gamma 130: guía para elegirla

<!-- AUDITORIA_EDITORIAL_178 -->

La **Gamma 130 Elite Red Line G2513AR** es una hidrolavadora eléctrica doméstica de agua fría. La pregunta práctica es si el caudal y los accesorios alcanzan para tus tareas habituales: Gamma la destina a vehículos, máquinas, embarcaciones, piletas, paredes y jardines. Sus **90 bar de presión máxima de servicio** son el dato de trabajo; **130 bar es la presión máxima admisible**, no la presión sostenida que debés esperar durante la limpieza.

## Gamma 130 G2513AR: prestaciones para decidir

| Dato | Gamma 130 Elite Red Line G2513AR |
| :--- | :--- |
| Alimentación y potencia | 220 VCA, 50 Hz; motor de 1.600 W |
| Presión | 90 bar máxima de servicio; 130 bar máxima admisible |
| Caudal | 360 L/h (6 L/min) |
| Manguera de alta presión | 5 m |
| Detergente | Tanque incorporado |
| Parada | Sistema AutoStop |
| Agua de entrada | 5–35 °C según la ficha local; presión de alimentación máxima 7 bar en el manual |
| Uso indicado | Doméstico: vehículos, máquinas, embarcaciones, piletas, paredes y jardines |

**AutoStop** detiene el motor cuando soltás el gatillo. El tanque de detergente permite usar detergente en la limpieza; seguí las indicaciones del manual sobre producto compatible y modo de aplicación. La ficha local destaca ruedas para trasladarla. No se publica el peso en la ficha consultada.

## ¿Me alcanza la Gamma 130?

| Tarea o situación | ¿Alcanza? | Criterio práctico |
| :--- | :--- | :--- |
| Auto, moto, bicicleta y herramientas | **Sí, para uso doméstico** | Son usos dentro de las tareas que Gamma declara. El caudal es 360 L/h y la manguera mide 5 m; considerá una extensión compatible si necesitás más radio. |
| Pileta, patio o paredes de una casa | **Sí, si el uso es ocasional o por sectores** | Gamma incluye estas superficies entre los usos domésticos. Para limpiar áreas grandes con frecuencia, el caudal y el alcance pueden hacer que el trabajo lleve más tiempo. |
| Suciedad adherida en una superficie pequeña | **Puede alcanzar** | Usá una boquilla adecuada y detergente compatible. Probá primero en un área discreta y mantené distancia para no dañar pintura, juntas o superficies blandas. |
| Grandes superficies o varias tareas repetidas en cada jornada | **Considerá subir de equipo** | La G2513AR está clasificada como doméstica. Si necesitás más caudal y tenés una diferencia de precio razonable, compará la Gamma 150 G2514AR; para trabajo sostenido, buscá un modelo dimensionado para uso intensivo. |

La guía de Gamma no asigna metros cuadrados por hora ni un ciclo continuo garantizado a la G2513AR. Por eso, “alcanza” aquí significa que el fabricante incluye esa clase de tarea entre sus usos domésticos; no promete una velocidad fija para cualquier superficie o suciedad.

## Cuándo conviene pasar a la Gamma 150

La **Gamma 150 Elite Red Line G2514AR** sigue siendo de uso doméstico, pero publica más caudal y una presión de servicio mayor. Elegila si valorás ese aumento para tareas domésticas más frecuentes o superficies extensas y el precio, el kit y el espacio de guardado justifican el salto. Si tus trabajos son ocasionales y principalmente vehículos, muebles o sectores chicos de patio, los datos oficiales no muestran que necesites subir sólo por el número “150”.

| Prestación | Gamma 130 G2513AR | Gamma 150 G2514AR | Diferencia publicada |
| :--- | ---: | ---: | ---: |
| Potencia | 1.600 W | 1.800 W | +200 W |
| Presión máxima de servicio | 90 bar | 100 bar | +10 bar |
| Presión máxima admisible | 130 bar | 150 bar | +20 bar |
| Caudal | 360 L/h | 400 L/h | +40 L/h |
| Manguera | 5 m | 5 m | Sin diferencia publicada |
| Detergente | Tanque | Tanque; dosificador regulable con control desde la lanza indicado por Gamma | Revisá si la regulación adicional te sirve |

Ambos modelos incluyen AutoStop, ruedas y se describen para uso doméstico. Las cifras son especificaciones publicadas por Gamma, no una comparación de rendimiento medida en la misma superficie. **La presión admisible no reemplaza a la presión de servicio** al valorar el salto.

Antes de pagar más, compará el precio de los dos artículos disponibles, el contenido exacto de la caja y el accesorio de detergente que trae cada versión. La página oficial consultada ofrece “Dónde comprar”, pero no muestra un precio único de venta; los valores pueden variar entre distribuidores.
